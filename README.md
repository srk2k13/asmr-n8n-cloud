# n8n ASMR Automation on Hugging Face Spaces

This is a free cloud deployment of n8n designed to run your ASMR automation pipeline 24/7 without needing your laptop to be switched on.

## How to use

1. Open your space URL (e.g., `https://huggingface.co/spaces/YOUR_USERNAME/YOUR_SPACE_NAME`).
2. Log in using the default user credentials or configure owner credentials using environment variables.
3. Import your workflow JSON `viral_asmr_n8n_workflow_FIXED.json`.
